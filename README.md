# Aestetic UI

Самостоятельная дизайн-система и библиотека административных интерфейсов для Laravel с живым каталогом. Для Codex подготовлен локальный MCP-адаптер.

Рабочее имя проекта: **AesteticUi**. Дата основания: 23 октября 2026 года. Composer-имя — `aestetic/ui`. Первый предварительный выпуск — [`0.1.0-alpha.1`](https://packagist.org/packages/aestetic/ui#v0.1.0-alpha.1); лицензия — [MIT](LICENSE).

## Для чего

Создавать опрятные, эстетичные и удобные админки с ясной навигацией. Проект даёт компоненты, композиции страниц, правила оформления и примеры, по которым человек и Codex могут последовательно собирать интерфейс.

Исходная админка Anilau служит референсом. Aestetic UI имеет собственную архитектуру, Git-историю, документацию и цикл выпуска; приложение-референс не является обязательным потребителем или зависимостью.

## Статус

Созданы концепция, архитектура, дорожная карта, каталог семейств компонентов и спецификация MCP. Для этапа 1 подготовлен [кликабельный дизайн-прототип трёх экранов](design/reference/index.html); [инструкция просмотра](design/reference/README.md). Визуальная приёмка ожидается.

Подготовлен локальный Composer-пакет: PSR-4 `Aestetic\Ui`, Laravel provider с package discovery, конфиг и готовые CSS/JS с manifest/хешами. Написаны 14 атомарных Blade-компонентов и три компонента основы — Scope/Page/Assets; контракты имеют статус `experimental`. Остальные семейства остаются `planned`.

Создан [Laravel-workbench с живым Blade-каталогом](workbench/README.md). Верхние разделы — «Компоненты» и «Подключение»; внутри есть группировка по задачам, правила UI/UX, Blade-примеры, 26 сценариев и API из общего реестра. Laravel 12.70.1 установлен, пакет подключён symlink. Ранее по поручению пользователя выполнен локальный запуск и открыта вкладка; рендеринг новой навигации и атомов проверен 175 запросами, затем повторён после установки пакета из ZIP без symlink: 175/175. Полная визуальная приёмка и проверка браузерных взаимодействий не завершены. Первый alpha-выпуск опубликован в GitHub и Packagist. Установка из публичного Packagist и рендеринг 175/175 также проверены во внутреннем workbench. Read-only MCP-адаптер реализован и по согласию пользователя зарегистрирован в Codex; соединение и вызовы tools ещё не подтверждены. Внешние проекты не подключались.

JSON-каталог различает исходный план и экспериментальные контракты существующего кода. Наличие исходников не доказывает работоспособность или готовность выпуска; `libraryVersion=0.1.0-alpha.2` описывает текущий alpha-выпуск; experimental и planned сохраняют свои ограничения.

## Подключение в Laravel

Пакет опубликован в [Packagist](https://packagist.org/packages/aestetic/ui), исходники и теги — в [GitHub](https://github.com/ChernyshovaAlexandra/AesteticUi). Совместимость `0.1.0-alpha.2`: **PHP `^8.3` и Laravel 12 или 13**. Поддержка Laravel 13 добавлена в Composer; runtime-проверки этого расширения не запускались. Границы выпуска — в [описании alpha.2](docs/laravel-13.md). Контракты experimental; между alpha-выпусками API может меняться.

[Инструкция установки, подключения и обновления](docs/installation.md) описывает оба пути, публикацию ассетов и текущие ограничения. [Первый Blade-пример](examples/getting-started.blade.php) использует реальные компоненты пакета. Локальное подключение выполнено только во внутреннем workbench, без подключения внешних проектов.

Установка из корня Laravel-приложения:

```sh
composer require "aestetic/ui:0.1.0-alpha.2"
php artisan vendor:publish --tag=aestetic-ui-assets
```

Затем подключить `<x-ui::assets />` в head и `<x-ui::scope>` вокруг интерфейса. Provider обнаруживается Laravel автоматически. Потребителю не нужны Node, Tailwind или сборка пакета. Дополнительный VCS/path-репозиторий для публичной установки не нужен. Ход подготовки и точные границы проверок: [первый выпуск](docs/first-release.md).

Локальный адрес дизайн-прототипа на текущем компьютере: **[http://aesteticui.test](http://aesteticui.test)** через Valet. Привязка указывает на `design/reference/`; [инструкция](design/reference/README.md#локальный-адрес-через-valet). HTTP и визуальная приёмка не выполнялись.

## MCP для Codex

В текущих исходниках есть read-only STDIO-сервер: поиск компонентов, API и Blade-исходник, правила применения, примеры и явные ответы для planned-композиций. Версия потребителя обязательна; сервер не подставляет latest и не сканирует Laravel-проекты. [Подготовка и команды подключения](tools/mcp/README.md). SDK устанавливается только для разработки; production UI от него не зависит.

Выпуск `0.1.0-alpha.1` не включает MCP executable; в `0.1.0-alpha.2` он включён. SDK устанавливается отдельно для запуска сервера. Подключение адаптера к Codex отражается отдельно; протокольные проверки не запускались.

## Первый результат разработки

Независимый Laravel-workbench с общей навигацией, тремя эталонными экранами — списком, карточкой и формой — и минимальным MCP-доступом к реализованным компонентам. Каталог и MCP развиваются вместе с библиотекой с самого начала.

Документация описывает будущий результат. Она не является командой запустить серверы, проверки, браузер или публикацию.
