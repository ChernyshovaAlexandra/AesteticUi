# Первый выпуск: 0.1.0-alpha.1

Дата подготовки: 23 октября 2026. Основание — поручение пользователя «делай все» после обсуждения публикации через GitHub + Packagist, включая предложенную проверку установки и рендеринга.

## Поставка

- Composer: `aestetic/ui`, версия из Git-тега `v0.1.0-alpha.1`; поле `version` в `composer.json` не задаётся.
- GitHub: `ChernyshovaAlexandra/AesteticUi`, публичный репозиторий создан, исходники ещё не отправлены.
- Совместимость: PHP `^8.3`, Laravel 12. Внутренняя проверка на Laravel 12.70.1.
- 14 атомов и Scope/Page/Assets, все контракты experimental. MCP и сложные planned-компоненты в поставку не входят.
- Готовые CSS/JS, package discovery, каталог API и оригинальные Lucide SVG с ISC-лицензией.
- Лицензия проекта — MIT. После пояснения пользователя, что проект пока не коммерческий, выбрана рекомендованная открытая лицензия; MIT также разрешает коммерческое использование кода другими людьми. Лицензия Lucide остаётся ISC.

## Выполненные проверки

Собраны поставляемые ассеты (`composer build:assets`) и ZIP (`composer archive`, версия задана через `COMPOSER_ROOT_VERSION`). Проверен состав ZIP: код, Blade, каталог, manifest и лицензия Lucide присутствуют; design, workbench, vendor, Git, `.tmp` и `.env` отсутствуют.

ZIP установлен обычным Composer-пакетом во внутренний workbench через временный package-репозиторий. Фактическая версия — `0.1.0-alpha.1`, каталог установки — `workbench/vendor/aestetic/ui`, symlink отсутствовал. Discovery и публикация CSS/JS завершились успешно. Это установка локального артефакта, не скачивание из Packagist.

Выполнены 175 запросов через HTTP Kernel: индекс, подключение, 17 страниц компонентов и 26 сценариев в трёх темах и двух плотностях. Результат: 175/175. Проверялись успешный статус, компиляция Blade, подключение CSS/JS и отдельные свойства разметки Input/Button/Select/Radio. Такой же набор прошёл и до установки архива.

После этого восстановлено исходное Composer path-подключение workbench с symlink на единственное дерево проекта. Основные `composer.json`/`composer.lock` workbench сохранены. Полные технические логи находятся в игнорируемой `.tmp/release/`.

Полная визуальная приёмка, клавиатурные сценарии в браузере и совместимость с другими версиями Laravel не подтверждены. Проверка установки опубликованной версии из Packagist ещё невозможна.
