ZIP установлен обычным Composer-пакетом во внутренний workbench через временный package-репозиторий. Фактическая версия — `0.1.0-alpha.1`, каталог установки — `workbench/vendor/aestetic/ui`, symlink отсутствовал. Discovery и публикация CSS/JS завершились успешно. Это установка локального артефакта, не скачивание из Packagist.

Выполнены 175 запросов через HTTP Kernel: индекс, подключение, 17 страниц компонентов и 26 сценариев в трёх темах и двух плотностях. Результат: 175/175.
