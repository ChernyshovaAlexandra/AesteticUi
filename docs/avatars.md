# Аватары и группы

Основание — прямое поручение пользователя от 23 октября 2026. Визуальный ориентир — [Avatar shadcn/ui](https://ui.shadcn.com/docs/components/avatar): круглая форма, нейтральная подложка и компактная группа с перекрытием.

## Оформление

- Размеры прототипа: small — 24px, обычный — 32px, large — 40px. Все размеры сохраняют круглую форму.
- Цвет текста, фона и тонкой рамки берётся из общей нейтральной палитры контролов; отдельной голубой подложки нет. Светлая и тёмная темы используют те же семантические переменные.
- Группа собирается из общего Avatar. Перекрытие составляет 6/8/10px в зависимости от размера. Постоянное разделение цветом поверхности помогает различать круги и не обозначает фокус.
- Если участников больше заданного лимита, последний круг показывает фактическое число оставшихся: `+2`, `+5`. Он не изображает кнопку без действия. Пустая группа не рендерится.
- Синие outline и focus-ring не добавляются. Статический аватар не получает tabIndex, hover-действие или роль кнопки.

## Семантика и примеры

Общий renderer находится в `design/reference/ui-components.js`. Существующий вызов `avatar(person, size)` сохранён: рядом уже есть имя человека, поэтому такой аватар декоративный. Для отдельного изображения используется третий параметр `{ decorative: false }` с доступным именем из `person.name`. Инициалы берутся из `person.initials` либо первых двух частей имени; без имени и инициалов показывается оригинальная Lucide Users.

`avatarGroup(people, { size, max, label })` по умолчанию показывает три аватара и при необходимости счётчик. Доступное имя группы перечисляет всех участников, включая скрытых за счётчиком. Не следует создавать группы с огромным списком людей: для полного состава нужен отдельный список участников приложения.

Примеры трёх размеров, неизвестного пользователя, обычной и компактной группы доступны в «Композиции компонентов» прототипа. Таблица, карточка клиента, контекстная панель и аккаунт бокового меню используют один renderer.

## Граница реализации

Прототип демонстрирует инициалы и fallback. Поддержка фотографий, их загрузки/ошибок и окончательный Blade API здесь не реализованы. Запись Avatar в реестре остаётся `planned`; наличие прототипа не означает готовность компонента Composer-пакета. Проверки и браузерная приёмка по этому изменению не выполнялись.
