## Composer-каркас — 23 октября 2026 года

D-30. По поручению пользователя «сделаем Composer-каркас… Пока без публикации» создан один корневой пакет с рабочим именем `aestetic/ui`, PSR-4 `Aestetic\Ui`, PHP `^8.3` и Illuminate `^12.0` (исходная граница D-10). Provider использует package discovery и регистрирует anonymous Blade-компоненты под `ui::`; отдельные PHP-классы для простых шаблонов не добавляются. Подготовлены Assets, Scope, Page и ограниченный текстовый Button; их реальный API отмечен `experimental`, будущие возможности семейств остаются planned. Работа с данными, авторизацией и маршрутами приложению не навязывается.

CSS хранится в `resources/css/`, поставка — в `dist/` с хешированным именем и manifest/SHA-256; `tools/build-assets.php` подготавливает последующие поставки без Node. Команда не запускается автоматически у потребителя. Публикация ассетов в приложение использует тег `aestetic-ui-assets`, конфиг — `aestetic-ui-config`. JS не добавлен до появления взаимодействий, которым он нужен; D-09 сохраняется для будущих интерактивных компонентов. Локальное подключение описано через Composer path с symlink на текущее дерево; никаких дополнительных копий/веток не создаётся. Инструкция: [installation.md](installation.md). Это граница текущей реализации, не изменение постоянных требований, не выпуск и не свидетельство проверенной совместимости. Лицензия и публичные координаты остаются открытыми.

## D-WB-01 — Laravel-workbench и единые Blade-сценарии

Основание — прямое поручение пользователя от 23 октября 2026 создать Laravel-workbench с живым каталогом, темами и состояниями, без публикации. В `workbench/` создано приложение Laravel 12 с Composer path/symlink на корень текущего дерева; зафиксирован `composer.lock`. Это приложение-потребитель внутри одного репозитория, без новой рабочей копии и без установки в Anilau. Приложению не требуются БД, миграции, Vite или Node; cache/session используют array-драйверы.

API, правила и список сценариев каталог читает из реестра подключённого пакета. `previews` ссылаются по фиксированному ID на `catalog/examples/<id>.blade.php`; тот же файл рендерится как Blade и показывается как исходник. Превью изолируются iframe, чтобы не смешивать темы и семантику Page/main с оболочкой. Тема, плотность и ширина задаются URL-параметрами с ограниченным набором значений, без JS. Planned-записи не получают выдуманных API/preview. Служебные навигация и таблица API каталога не объявляются реализацией planned-компонентов библиотеки.

В ходе реализации выполнены локальная установка Laravel 12.70.1, discovery и копирование CSS посредством Composer-scripts. Сервер, HTTP/браузерные проверки и визуальная приёмка не выполнялись. Runtime-флаг компонентов остаётся false. Документ не разрешает публикацию, запуск проверок или изменение постоянных требований. Инструкция: [workbench/README.md](../workbench/README.md).

В реестр добавлены componentGroups/catalogGroup, русские имена, guidance и общая installation. Страница компонента объясняет выбор, размещение, ограничения и подключение перед демонстрациями. Добавлены 13 атомов к Button, расширен сам Button; с основой интерфейса это 17 experimental-контрактов и 26 сценариев. Компоненты рендерят собственные Blade, CSS и JS; иконки — только оригинальные Lucide. Поля даты/времени и сложные композиции не объявляются реализованными. Исправлен отсутствовавший componentGroups, показанный пользователем; реестр сохраняется заменой временного файла. Это изменения исходников и локальных ассетов, без проверок/новой браузерной приёмки, публикации и внешних потребителей. [Подробности](atomic-catalog.md).

## D-37 — Sheet и нижняя панель

По U-35 от 23 октября 2026 добавлен общий SheetContent с header/body/footer и вариантами справа, слева и снизу. Панели используют существующий dialogs.show с подстановкой renderer, нативную модальность и очистку; общий runtime возвращает фокус и обрабатывает нажатие на затемнение. Мобильная навигация использует тот же SheetContent, отдельная старая геометрия drawer удалена. Нейтральная палитра, отдельная прокрутка тела, общие кнопки, reduced motion; без синих outline/focus-ring. Примеры находятся в «Композиции компонентов». [Правила](panels.md). Реализован прототип без жестов перетаскивания; Blade API остаётся planned. Проверки и браузерная приёмка не выполнялись.

## D-38 — Popover и ContextMenu

По U-36 от 23 октября 2026 общий Popover получил нейтральную поверхность, заголовок/описание, слот содержимого и действия. ContextMenu использует тот же renderer пунктов и runtime, что ActionMenu; открывается в точке правого клика только внутри явно заданной области, с клавиатуры либо обычной кнопкой. Координатор popup получил необязательную точку привязки и callback закрытия, чтобы состояние меню/поповера сбрасывалось при общем закрытии. Примеры — «Поля и выбор». [Правила](overlays.md). Без синих outline/focus-ring. Реализован прототип с одним активным popup; вложенные интерактивные popup и Blade API не реализованы. Проверки и браузерная приёмка не выполнялись.

## Открытые решения

- Финальное написание бренда; доступность `aestetic/ui` и выбранного namespace.
- Публичная публикация `aestetic/ui` в GitHub + Packagist ещё не завершена. MIT выбрана, GitHub owner/URL определены в D-RELEASE-01.
- Точная палитра, типографика, числовые токены и вид общей навигации — после эталонных экранов.
- Подтверждённая матрица PHP/Laravel/браузеров, build/test/dev-зависимости.
- Конкретный формат полного API-дескриптора и сборки ассетов — после первого вертикального среза.
- Хостинг визуального каталога и удалённого MCP, способ аутентификации при необходимости.
- Первый реальный проект-потребитель. Референс не считается автоматически выбранным пилотом.
- Удобство Storybook-адаптера, если его преимущества оправдают поддержку; два независимых источника разметки не планируются.

Открытые вопросы не препятствуют сохранению концепции и разработке каркаса. Решения о распространении нужны до распространения, а не для создания этих документов.
