# Решения и открытые вопросы

## Рабочие решения — 23 октября 2026 года

Это технические решения для дальнейшей реализации, а не постоянные требования пользователя.

| ID | Решение | Причина / граница |
| --- | --- | --- |
| D-01 | Рабочее имя Aestetic UI, папка AesteticUi | Название предложено пользователем; окончательный бренд можно уточнить |
| D-02 | Один независимый репозиторий | Самостоятельный продукт, без изменения референса |
| D-03 | Laravel/Blade — первая реализация | Подтверждённый целевой стек |
| D-04 | Навигация и page patterns входят в первую версию | Основная часть задачи, а не позднее украшение |
| D-05 | Каталог с реальными Blade-компонентами | Избежать второй разметки и расхождения с поставкой |
| D-06 | Laravel-native каталог — исходный путь | Storybook не предоставляет Blade manifest API из коробки; отдельный адаптер возможен позже |
| D-07 | Общие versioned metadata для каталога и MCP | Одни правила выбора и примеры для человека и агента |
| D-08 | MCP read-only; STDIO первым, HTTP позже | Сначала короткий локальный путь чтения знаний без обязательного хостинга |
| D-09 | Готовые CSS/JS в Composer-поставке | Потребителю не нужна специальная frontend-конфигурация |
| D-10 | Исходная среда PHP 8.3 / Laravel 12 | Стартовая граница реализации; совместимость ещё не подтверждена |
| D-11 | JSON-инвентаризация содержит planned, без API | Не выдавать проектируемое за реализованное |
| D-12 | Собственная визуальная система | Референс даёт материал, но частные ограничения его продукта не определяют библиотеку |

## Открытые решения

- Финальное написание бренда; доступность `aestetic/ui` и выбранного namespace.
- Публичная/частная лицензия и канал распространения. Лицензия исходного кода сейчас не назначается; внешняя публикация не выполняется.
- Точная палитра, типографика, числовые токены и вид общей навигации — после эталонных экранов.
- Подтверждённая матрица PHP/Laravel/браузеров, build/test/dev-зависимости.
- Конкретный формат полного API-дескриптора и сборки ассетов — после первого вертикального среза.
- Хостинг визуального каталога и удалённого MCP, способ аутентификации при необходимости.
- Первый реальный проект-потребитель. Референс не считается автоматически выбранным пилотом.
- Удобство Storybook-адаптера, если его преимущества оправдают поддержку; два независимых источника разметки не планируются.

Открытые вопросы не препятствуют сохранению концепции и разработке каркаса. Решения о распространении нужны до распространения, а не для создания этих документов.

## Как изменять

Записывать ID, новое решение, причину и затронутые контракты. Изменение решения не переписывает требования пользователя. Статус реализации обновляется отдельно в плане.
