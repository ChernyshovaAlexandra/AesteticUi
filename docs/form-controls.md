# Поля ввода и выбор

Основания: U-15 — собственные эстетичные компоненты всех полей и селектов; U-18 — собственные календарь и выбор времени вместо браузерных. Ориентир shadcn/ui из U-13: спокойная поверхность, тонкая рамка, компактная геометрия и читаемый контент. Фокус использует изменение существующей нейтральной рамки без синей обводки (U-14). Иконки — только оригинальные Lucide (U-11).

## Направление и граница реализации

В `design/reference/` написаны общие оформление и взаимодействия полей. Они применяются к трём экранам, параметрам макета и диалогам. В «Параметры макета → Поля и выбор» находятся примеры типов и состояний. Это панель дизайн-прототипа, не живой каталог библиотеки.

Blade-компоненты и versioned API пока не реализованы; реестр сохраняет `planned`. По прямому запросу пользователя выполнена [узкая браузерная проверка оформления](form-controls-review-2026-10-23.md): рамки, размеры и раскрытие панелей. Полная функциональная проверка, проверка со скринридером и визуальная приёмка пользователем не выполнены.

## Семейства

| Контрол | Назначение и оформление |
| --- | --- |
| Текст, email, телефон, URL | Общая поверхность и рамка; соответствующие нативные типы, автозаполнение и раскладка устройства |
| Поиск | То же поле; в фильтре списка — Lucide Search и отдельная подпись |
| Пароль | Поле с текстовым действием «Показать / Скрыть» и состоянием `aria-pressed` |
| Число | Значение с табличными цифрами, собственные кнопки шага с Lucide; `min`, `max`, `step` остаются у нативного input |
| Textarea | Общая поверхность, вертикальное изменение размера; подсказка и счётчик принадлежат Field |
| Select | Собственное закрытое поле и всплывающий список; выбранные пункты отмечаются Lucide Check |
| Multiple Select | Тот же список с несколькими выбранными пунктами; значения перечислены в поле, выбор сохраняет список открытым |
| Дата, время, дата со временем, месяц, неделя | Собственные календарь, выбор месяца/года и времени; нейтральная палитра контролов и Lucide, без браузерного picker |
| Checkbox | Нативное значение и фокус; собственная рамка, Lucide Check и отдельное indeterminate-состояние |
| Radio | Нативная группа одного выбора; общая геометрия и цвет выбранного значения |
| Switch | Нативный checkbox с ролью switch; переключает только локальное значение |
| Диапазон (`input[type=range]`) | Собственные дорожка и бегунок; нативные шаг и клавиатура. Не путать с запланированным Range — парой полей от/до |
| Файл | Оформленное нативное поле и кнопка выбора; системный диалог и доступ к файлам остаются у браузера |
| Цвет | Оформленная поверхность со swatch; системная палитра остаётся нативной |

Кнопки отправки/сброса относятся к Button/FormActions, скрытые inputs не имеют визуального представления. По U-18 дата и время используют собственные панели; диалоги файла и цвета остаются системными.

## Состояния и выбор

- Подпись всегда доступна независимо от placeholder; подсказка и ошибка связаны с контролом.
- Пустое и заполненное поле используют одинаковую геометрию. Фокус меняет существующую рамку, не добавляет синий ring.
- Ошибка получает текст и `aria-invalid`, цвет лишь дополняет сообщение.
- Disabled блокирует взаимодействие. Readonly сохраняет значение, а в текстовых полях позволяет выделить/скопировать его.
- Select хранит значение в нативном select для `FormData`; пользователь и средства доступности взаимодействуют с одним видимым combobox, скрытый select не дублирует его.
- Стрелки перемещают активный пункт; Home/End — начало/конец; Enter/Space выбирают; Escape закрывает; Tab закрывает и продолжает обычный порядок фокуса. Набор начала названия перемещает активный пункт без отправки формы.
- Недоступные варианты пропускаются. Выбранное и активное состояния различимы: отметка значения и нейтральный фон перемещения.
- Список открывается над или под полем с учётом места. Popover выводит его над обрезающими контейнерами и внутри modal dialog. Раскрытие в диалоге проверено в Chrome; матрица совместимости не утверждена. Прокручивается только сам список, без перемещения родительского диалога.
- Для короткого перечня без поиска используется Select; поиск по большому/удалённому набору относится к будущему Combobox. Radio полезен, когда небольшое количество вариантов должно быть видно сразу.

## Календарь и время

У Date, Month и Week общая панель календаря с понедельника, переходами между месяцами, отметкой сегодня и выбранного значения. Нажатие на заголовок открывает сетку месяцев и редактируемый год от 1 до 9999. Выбор недели сохраняет ISO week-year и номер недели, включая границы года. «Сегодня» и «Очистить» — явные действия.

TimePicker показывает прокручиваемые колонки часов и минут в 24-часовом формате. Секунды появляются для значения/ограничения с секундами или соответствующего `step`; точность прототипа — целая секунда, дробные секунды не представлены. Доступные варианты учитывают `min`, `max`, `step`, в том числе диапазон времени через полночь. Неподходящие варианты недоступны; система не записывает их в input.

Datetime-local объединяет календарь и время. Выбор даты обновляет доступное время; «Готово» сохраняет оба значения вместе. Time также подтверждается через «Готово». Date, Month и Week применяются при выборе. Закрытие без подтверждения времени оставляет исходное значение. Disabled блокирует контрол, readonly сохраняет видимое значение без открытия панели.

Кнопка поля открывает немодальный popover с ролью dialog; родительский modal dialog поддерживается тем же механизмом размещения, что и Select. Escape закрывает панель и возвращает фокус к полю. В календаре стрелки перемещают фокус, Home/End переходят к краям недели, PageUp/PageDown меняют месяц, с Shift — год. Enter/Space выбирают день. В колонках времени ArrowUp/ArrowDown и Home/End перемещают фокус, Enter/Space выбирают значение. Синие outline/focus-ring не добавляются.

Скрытый исходный input сохраняет имя, ISO-значение, ограничения и участие в FormData. Видимое поле связано с исходной подписью; браузерный date/time picker не вызывается. Гражданские дата и время не переводятся в UTC timestamp приложения: UTC-арифметика применяется только внутри календаря, чтобы смена часового пояса и DST не сдвигали дни. Серверная валидация остаётся у потребителя.

Примеры включают обычные дату/время, datetime, месяц, неделю, секунды, ограниченный диапазон дат, время с шагом 15 минут, disabled и readonly. Оформление, раскрытие календаря/времени и клавиатурная прокрутка колонки часов проверены в Chrome; полный функциональный контракт и приёмка пользователем остаются неподтверждёнными.

## Владение кодом

`controls.css` владеет внешним видом и состояниями, `controls.js` — улучшением нативных контролов и управлением Select. `date-time-controls.js` и `date-time-controls.css` владеют собственными календарём и выбором времени и используют общий popover-механизм из `controls.js`. `control-examples.js` содержит примеры для панели просмотра. Страницы сохраняют подписи, ограничения и значения, а `app.js` — демонстрационные сценарии.

При переносе в Laravel компоненты владеют разметкой, стилями и клавиатурой, Field — label/hint/error, приложение — данными, правами, валидацией на сервере и сетевыми операциями. Свидетельства приёмки и совместимость добавляются по факту, без автоматического изменения статуса `planned`.
