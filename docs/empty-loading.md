# Пустые состояния и загрузка прототипа

Оформление от 23 октября 2026 по прямому поручению пользователя: общий стиль shadcn/ui без синих outline. Ориентиры — [Empty](https://ui.shadcn.com/docs/components/empty) и [Skeleton](https://ui.shadcn.com/docs/components/skeleton). Существующий прототип остаётся локальным HTML/CSS/JS, без установки React и стороннего runtime.

## Пустое состояние

Общий `empty()` рендерит иконку Lucide Package в нейтральной области 40px, заголовок 18/24px, пояснение 14/22px и отдельную область действия с существующей Button. Иконка 24px, радиусы и цвета согласованы с контролами. Ширина текстовой области ограничена 380px, расстояние до действия — 24px. Отступы 48px/24px на широком экране и 32px/20px на маленьком; блок центрирует содержимое без дополнительной яркой рамки.

Тексты и действия прежние: нет заказов, ничего не найдено по фильтрам, нет данных клиента, форма недоступна в демонстрационном пустом состоянии. Действие остаётся ссылкой или кнопкой; отсутствие данных не обозначается красным как ошибка.

## Загрузка

Общий `loadingView()` выбирает композицию по существующему экрану и вкладке:

- список заказов и вкладка заказов — группы строк со скелетонами текста, аватара и статуса;
- форма — группы подписей и полей;
- обзор клиента — подписи, значения и текстовые блоки;
- история — повторяющиеся строки с маркером и текстом.

Скелетоны не являются настоящими контролами и не получают tabindex. Декоративная область скрыта от screen reader через `aria-hidden`; существующая роль status используется для видимой подписи «Загружаем данные…» с Lucide Clock.

Палитра — нейтральный `--control-secondary` light/dark, радиусы повторяют текстовые контролы, бейджи и аватары. Пульсация только через opacity с периодом 2s; общее правило reduced motion отключает анимацию. Списки допускают горизонтальную прокрутку, сетка полей на маленьком экране становится одноколоночной. Самостоятельные состояния формы получают общую поверхность карточки.

Синие CSS-outline, focus-ring, цветные блики и новые интерактивные элементы не добавляются.

## Граница готовности

Изменены общие render helpers и стили прототипа. Примеры доступны через существующие «Параметры макета → Состояние → Пусто / Загрузка». Это переключение демонстрационного состояния, не сетевые запросы и не доказательство интеграции с backend. Проверочные запуски, браузерная и визуальная приёмка не выполнялись. Библиотечные семейства остаются `planned`.
