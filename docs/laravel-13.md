# Laravel 13 и 0.1.0-alpha.2

Основание: прямое поручение пользователя от 23 октября 2026 добавить поддержку Laravel 13 в AesteticUi, выпустить новый alpha-релиз и установить его в mts33-backend через Packagist.

## Изменение

В Composer ограничения `illuminate/contracts`, `illuminate/support` и `illuminate/view` расширены с `^12.0` до `^12.0 || ^13.0`. Требование PHP остаётся `^8.3`. Laravel 12 продолжает поддерживаться; понижение Laravel у потребителя не требуется.

Provider использует штатные mergeConfigFrom, loadViewsFrom, anonymousComponentPath, singleton и publishes. Подключение CSS/JS использует контракт UrlGenerator. Эти API доступны в исходниках установленного Laravel 13 потребителя; изменения PHP-кода и Blade-компонентов для расширения ограничений не потребовались. Это вывод по исходникам, а не подтверждение runtime-поведения.

Реестр компонентов обновлён до `libraryVersion=0.1.0-alpha.2`, чтобы MCP различал контракт установленной версии. Статусы experimental/planned и свойства компонентов не меняются. В историю перед этим выпуском уже включён read-only MCP executable; SDK остаётся отдельной необязательной зависимостью разработки. Параллельные незавершённые изменения дизайн-прототипа в выпуск не входят.

## Установка

```sh
composer require "aestetic/ui:0.1.0-alpha.2"
php artisan vendor:publish --tag=aestetic-ui-assets
```

Provider обнаруживается стандартным Laravel package discovery. В head подключается `<x-ui::assets />`, а новые компоненты оформляются в `<x-ui::scope>`. Миграции и данные БД библиотека не добавляет.

## Граница готовности

Изменены декларация совместимости, версия реестра и документация. Тесты, lint, validation builds, HTTP- и визуальные проверки для Laravel 13 не запускались: отдельного поручения на них не было. Публикация и установка у потребителя отражаются отдельно по факту выполнения; результаты проверок alpha.1 на Laravel 12 не подтверждают Laravel 13.
