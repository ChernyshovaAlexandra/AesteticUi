# История изменений

## 0.1.0-alpha.1 — 2026-10-23

Первый предварительный выпуск для PHP 8.3+ и Laravel 12. Опубликован в GitHub и Packagist 23 октября 2026 года.

- Composer-пакет `aestetic/ui`, PSR-4 и автоматическое обнаружение Laravel provider.
- 14 атомарных Blade-компонентов: Icon, Button, Link, Spinner, Status, Input, Textarea, Select, Checkbox, Radio, Switch, FileInput, Avatar, Thumbnail.
- Scope, Page и Assets для темы, плотности и подключения готовых CSS/JS.
- Оригинальные иконки Lucide с сохранённой ISC-лицензией.
- Реестр API, правила выбора и размещения, 26 исполняемых Blade-сценариев.
- Внутренний Laravel-workbench с разделами «Компоненты» и «Подключение».

Контракты экспериментальные и могут меняться между alpha-выпусками. Сложные компоненты со статусом `planned`, MCP и публичный хостинг каталога в этот выпуск не входят. Визуальная приёмка и проверка полного набора браузерных взаимодействий пока не завершены.
