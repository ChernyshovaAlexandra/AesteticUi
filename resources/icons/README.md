# Lucide в Blade-пакете

Оригинальные SVG из локальной подборки прототипа; геометрия не изменялась. Upstream: https://github.com/lucide-icons/lucide/tree/20aef31db93fe4d9f398dbb15b120d99c48eef95/icons

icons.json содержит исходную разметку. IconSet выбирает только существующее имя и добавляет корневому SVG aria-hidden/focusable; доступное имя задаётся обёртке Icon через label. Лицензия upstream находится в LICENSE. Другие наборы и самодельные геометрии не используются.
